# Evren ile Çay Sohbeti

Bu repository, insanlık tarihinin en önemli bilimsel ve felsefi sorusuna cevap aramaktadır:

**Çay demlenirken evren ne düşünüyor?**

## Nasıl Çalışır?

```bash
python cay_demle.py
```

Kod, suyu ısıtır, çayı demler, sonra kettle ile tartışır, sonra evreni arar, sonra varoluşsal kriz geçirir. Tamamen gerçek ve çalışan bir simülasyondur. Lütfen laboratuvar ortamında kullanın.

## Özellikler

- Sonsuz (neredeyse) çay demleme döngüsü
- Kettle'in küçümsemeleri
- Evrenin fısıltıları
- Rastgele varoluşsal krizler
- Hiçbir şey yapmayan ama çok ciddi görünen fonksiyonlar

## Uyarı

Bu kod çalışırken gerçek çay demlenmez. Sadece terminalinizde çay demlenir. Yan etkileri: Aşırı ciddiyet hissi ve çay içme isteği.
